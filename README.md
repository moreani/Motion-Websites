# Motion Websites — 20 cinematic demo pages

Live gallery: **https://moreani.github.io/Motion-Websites/**

Twenty standalone landing pages built with the [MotionSites Web Builder](https://github.com/Motionsites-AI/claude-skill) skill: its prompt library, technique recipes, media shelf, and a screenshot-and-fix QA loop.

Each demo is a single `index.html` — Google Fonts and pinned CDN libraries only, no build step, no local assets. Hero videos and images are loaded from the skill's public media shelf.
